# Moonlighter Price Guide

A small, fast price reference for **Moonlighter** and **Moonlighter 2**.

![Static site](https://img.shields.io/badge/static-HTML%20%2F%20CSS%20%2F%20JS-4f8f72?style=flat-square)
![GitHub Pages](https://img.shields.io/badge/hosted%20on-GitHub%20Pages-24292f?style=flat-square)

I made this to check prices faster while playing. **Search an item, see the recommended price, avoid overpricing or underpricing, mark items you’ve already priced, export your item checks, import them later, and get back to playing.**


## Features

- Moonlighter + Moonlighter 2 in one site
- Fast item / relic search
- Dungeon, region and rarity filters
- Checked-item tracking
- Progress import / export
- Moonlighter 2 quality, popularity, furniture and shift-perk calculator
- Responsive desktop and mobile layout

## Price data

**Moonlighter**  
Prices are based on the [TrueAchievements Moonlighter walkthrough](https://www.trueachievements.com/game/Moonlighter/walkthrough/9).

**Moonlighter 2**  
Relic prices are based on the [Steam Community guide by Dorce](https://steamcommunity.com/sharedfiles/filedetails/?id=3730368034).

Moonlighter 2 shop mechanics are also referenced from [Prima Games](https://primagames.com/tips/moonlighter-2-shop-guide-pricing-furniture-perks-explained) and [Pro Game Guides](https://progameguides.com/moonlighter-2-the-endless-vault/moonlighter-2-shop-relics-guide-how-to-earn-more-gold/).
